# PasswordApp

Modern desktop UI shell for a future password manager application.

## Current Scope

This project is intentionally **UI only**:
- No business logic
- No networking or API calls
- No database integration
- No authentication flows

## Tech Stack

- Python 3.12+
- Tkinter / ttk
- ttkbootstrap

## Run Locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

The interface includes a polished application frame, sidebar navigation, dashboard cards, data table placeholders, and a status bar ready for future integration.
